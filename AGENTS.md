# Project instructions

- Do not create a Git commit unless the user explicitly asks for one.
- Do not add PowerShell (`.ps1`) scripts as project deliverables. Use Bash (`.sh`) or Python for persistent helper scripts; one-off PowerShell shell commands are acceptable.
- For Android changes, run the relevant automated tests and the Android lint task (`:app:lintDebug`) before handing the work back. Report any checks that could not be run or did not pass.
